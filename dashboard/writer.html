New entry

This becomes /writing/your-address. You can edit it before saving.

Drafts are saved in this browser. Writing is not sent to the dashboard or an online service.

Publishing opens a local terminal. The browser may ask whether to open Ghostty; the terminal requires you to type PUSH before publishing.

What gets updated?

Open this desk once while online so its files are cached. After that, drafts and previews work offline. Article entries create writing/<address>.html, add a card to the home page and the selected section, and update the sitemap. News/status entries go to the top of Status Updates and the home page’s current-status list. The editor only writes to the folder you choose. Choose Publish site… to review changed files in a terminal and approve the GitHub Pages, Cloudflare Pages, and status-service deployment.
